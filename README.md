# RiceWise – Sales & Demand Monitoring and Forecasting Dashboard

RiceWise is a sales and demand monitoring and forecasting dashboard developed for a small rice retail business in Plaridel, Bulacan.

The system analyzes historical sales data, monitors sales trends, examines seasonal demand patterns, and generates demand and sales forecasts for different rice varieties.

## Project Objectives

- Monitor historical sales performance
- Analyze sales trends across rice varieties
- Examine seasonal demand patterns
- Generate demand and sales forecasts
- Apply data analytics and machine learning techniques
- Compare forecasting model performance

## Key Features

- Sales monitoring
- Sales analytics
- Seasonal analysis
- Demand forecasting
- Sales forecasting
- Interactive dashboard

## Technologies Used

- React.js
- Python
- Machine Learning
- Data Analysis
- Data Visualization
- Git & GitHub
