# 🌾 RiceWise – Sales & Demand Monitoring and Forecasting Dashboard

RiceWise is a sales and demand monitoring and forecasting dashboard developed for a small rice retail business in Plaridel, Bulacan.

The system analyzes historical sales data, monitors sales performance, examines seasonal demand patterns, and generates demand and sales forecasts for different rice varieties through an interactive web-based dashboard.

## 🎯 Project Objectives

- Monitor historical sales performance
- Analyze sales trends across different rice varieties
- Examine seasonal demand patterns
- Generate demand and sales forecasts
- Apply data analytics and machine learning techniques
- Compare forecasting model performance
- Present insights through an interactive dashboard

## ✨ Key Features

### 📊 Sales Monitoring
- View sales performance across different rice varieties
- Monitor sales trends over time
- View summarized sales information through charts and tables

### 📈 Sales Analytics
- Analyze sales patterns and trends
- Compare rice variety performance
- View graphical and tabular sales information

### 🌦️ Seasonal Analysis
- Analyze demand patterns across different seasons
- Compare rice sales during dry and wet seasons
- Identify changes in demand over time

### 🔮 Demand & Sales Forecasting
- Generate forecasts using historical sales data
- Forecast demand for different rice varieties
- Present forecast results through interactive visualizations
- Compare forecasting model performance

### 📁 Data Management
- Import sales data for analysis
- Process and prepare data for analytics and forecasting
- Display processed results through the dashboard

## 🛠️ Technologies Used

- **React.js** – Interactive web interface
- **Python** – Data processing and forecasting
- **Machine Learning** – Forecasting and model development
- **Data Analysis** – Historical sales and demand analysis
- **Data Visualization** – Charts, graphs, and dashboard visualizations
- **Git & GitHub** – Version control and project management

## 📸 System Preview

### Login & Landing Page
RiceWise provides a dedicated login interface and landing page for accessing the system.

### Dashboard
The main dashboard provides an overview of sales performance through interactive charts, summary information, and visualizations.

### Sales Analytics
The sales analytics pages provide detailed views of sales trends and performance across rice varieties.

### Seasonal Analysis
The seasonal analysis pages visualize changes in rice demand and sales patterns across different periods.

### Forecasting
The forecasting pages present demand and sales forecast results using historical sales data and forecasting models.

### Data Management
The system also includes pages for managing and importing data used for analysis and forecasting.
